eMAG AutoBuy

Un dashboard Python local pentru monitorizarea produselor eMAG și pregătirea unui coș cu mai multe produse.

Vezi codul pe GitHub Instalare Windows 11

Rulează pe calculatorul tău

Dashboardul, profilul browserului, sesiunea eMAG și baza SQLite rămân locale. Descarcă proiectul și urmează instrucțiunile din README.

Pagina aceasta este statică. Nu se conectează la contul tău și nu poate adăuga produse sau trimite comenzi.

Verifică înainte de folosire

Modul Test este activ implicit. Site-ul eMAG și fluxurile de checkout se pot schimba; verifică manual produsul, prețul, cantitatea și taxele. CAPTCHA și 3‑D Secure rămân manuale.

Piețe acceptate

Versiunea curentă acceptă numai eMAG România. Bulgaria și Ungaria necesită inspecția separată a paginilor și checkouturilor reale; fiecare țară are coș și comandă separate.
